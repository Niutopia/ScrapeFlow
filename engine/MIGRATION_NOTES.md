# v3.3.2 迁移说明

## 从 v3.2.x / 早期脚本迁移

- 默认永远是 dry-run；实时扫描结果不能直接写入远端。
- 真正执行必须加载已保存计划，并提交计划显示的完整 SHA-256。
- `--password` 与 `--tmdb-key` 明文参数已移除，改用环境变量或密码文件。
- 电视剧源必须至少包含一个可识别视频；只有字幕或压缩分卷时会停止。
- `--cleanup-empty-source` 不再默认启用；原压缩包也不会自动删除。
- 无法可靠映射的绝对集数、小数集数或特别篇默认停止，不再按文件排序猜测。
- AList 远程明文 HTTP 只允许环回地址；其他地址必须使用 HTTPS 或明确承担风险。

## v3.3.2 变化

- 新增 AList 原生分卷归档解压、密码标记发现、解压任务等待与结果校验。
- 归档解压最低安全版本为 AList v3.57.0。
- 新增 `11.5` / `18.5` 小数回顾篇的显式覆盖映射。
- 修复字幕组 `[02v2]` 格式：`02` 是集号，`v2` 是修订号。
- 禁止从 `[01-23 Fin v2]` 这类发布包父目录错误推断为第 1 集。
- 计划、journal、锁、快照和目标身份校验保持向后兼容。
